# grade-calculator.
## Functional Requirements
The program shall prompt the user to enter a student's name or end to stop entering students.
The program shall read exactly 5 whole-number scores from 0 to 100 for each student.
The program shall display an error message and re-prompt for the same score if an entered score is outside the 0–100 range.
The program shall calculate each student's average score and assign a letter grade (A for 90–100, B for 75–89.99, C for 60–74.99, and F for below 60).
The program shall display the total number of students entered and the overall class average once end is entered.


## Grading scale
| Grade | Average |
|-------|---------|
| A | 90 - 100 |
| B | 75 - 89.99 |
| C | 60 - 74.99 |
| F | Below 60 |
